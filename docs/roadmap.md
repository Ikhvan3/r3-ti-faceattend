# Roadmap

Pengembangan dilakukan bertahap agar fondasi lokal stabil sebelum fitur
absensi dan face recognition ditambahkan.

## Urutan Implementasi

1. Environment verification.
2. Repository scaffolding.
3. Golang health endpoint dan koneksi PostgreSQL.
4. Database migrations.
5. Admin authentication.
6. Employee management.
7. Flutter authentication.
8. Basic check-in dan check-out tanpa face recognition.
9. Admin attendance dashboard.
10. Geolocation.
11. Face enrollment dan verification.
12. Basic liveness detection.
13. Attendance corrections dan reports.

## Di Luar Scope Saat Ini

- Multi-divisi.
- Payroll.
- Leave management.
- Shift management.
- Production deployment.
